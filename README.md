# 贴吧 Nova

面向 AstrBot 的独立贴吧解析插件。发送贴吧帖子链接即可获取主楼正文、原图、视频和楼层回复；无需安装 Nova 流媒体解析插件。

## 功能

- 支持标准帖子 `/p/帖号`、移动端 `kz` / `tid`、旧 WAP 帖子入口和移动视频分享链接。
- 获取主楼标题、正文、作者、头像、吧名、发布时间及接口提供的点赞数、回复数。
- 提取主楼原图和签名视频地址；回复中的图片、视频只显示内容摘要，避免混入主楼媒体。
- 可选首屏楼层回复，按真实楼层顺序展示，默认 3 条。真实点赞缺失时显示未知，0 赞正常保留。
- 卡片支持深浅配色、四种布局和可选皮肤，正文与回复可选翻译。
- 自动解析、关键词触发、引用消息解析及 JSON 分享卡片提链。
- 图片、视频、合并转发、ZIP 导出、权限控制及同链接 / 同用户频率限制。
- 超过普通视频发送上限时，默认直接发送原文件，跳过压缩；支持 QQ 群文件与私聊文件。
- 独立配置、缓存标记、限流记录和日志；卸载时取消正在处理的任务并关闭网络会话。

## 安装和使用

1. 使用 AstrBot `>=4.25.0,<5`，推荐 Python 3.12 或 3.13。
2. 在插件管理中通过仓库地址安装：

```text
https://github.com/Whereis-Alice/astrbot_plugin_tieba_nova
```

3. 保持默认配置、Cookie 留空，发送一个可公开访问的贴吧帖子链接。

```text
https://tieba.baidu.com/p/11180655858
```

默认自动解析、卡片开启、卡片模式为“仅卡片”；主楼图片和视频仍会按富媒体设置发送。若关闭自动解析，可发送 `贴吧解析 <链接>` 或 `解析贴吧 <链接>`。启用“回复触发解析”后，引用含链接的消息并附上同样的关键词即可解析。配置管理员 ID 后，管理员可私聊发送 `清理贴吧媒体` 清理本插件缓存。

Linux / Docker 环境需要可用中文字体，例如 Debian / Ubuntu 的 `fonts-noto-cjk`；安装在 AstrBot 实际运行的容器或环境中。也可在“自定义字体路径”中指定本机字体文件。视频校验及可选压缩需要 `ffmpeg` / `ffprobe` 在同一运行环境中可用。

## 配置要点

| 设置 | 默认行为 |
| --- | --- |
| 贴吧输出模式 | 全部发送，可选关闭、仅文本、仅富媒体 |
| 楼层回复 | 获取 3 条，合并到卡片，不另发回复文本 |
| 卡片模式 | 仅卡片，可改为与文本同条或分开发送 |
| 普通视频发送上限 | 48 MiB |
| 超限视频投递 | 直接上传原文件，不压缩 |
| 视频下载硬上限 | 1000 MiB，超限停止下载 |
| Cookie、代理、翻译 | Cookie 留空，代理与翻译关闭 |

原文件投递使用 AstrBot 的 aiocqhttp / OneBot v11 接入。NapCat、SnowLuma、LLBot 等协议端需支持文件上传并能读取下载文件的本地路径；群聊还需有上传群文件的权限。协议端和 AstrBot 分离容器部署时，需将下载目录共享给协议端，并保持上传路径可读。平台不支持文件上传或上传失败时，会保留状态提示和可用封面。

可选媒体中转通过 AstrBot 文件服务传输普通图片和视频；分离部署时需要协议端可访问的 `callback_api_base`。这一设置不会把群文件 / 私聊文件上传路径转成 HTTP 地址。

“超限直接上传原文件（不压缩）”会跳过超限视频压缩，即使压缩策略另设为“始终压缩”，超限视频也保留原文件。下载硬上限仍然有效。

正文和回复翻译可使用 AstrBot 已配置的模型，或自定义接口。翻译默认关闭；Cookie 和翻译 API Key 仅保存在本机配置中。

ZIP 导出默认未设置命令。可在“归档命令”中填写例如 `贴吧打包`，引用含帖子链接的消息后发送该命令。导出不受聊天“仅文本／仅富媒体”的展示模式影响，仍遵循贴吧启用开关、回复获取设置、权限、限流及下载体积限制。

## 与 Nova 同时安装

原 [Nova 流媒体解析](https://github.com/Whereis-Alice/astrbot_plugin_media_parser_nova) 中的贴吧实现保留。两个插件可以同时安装，独立配置并自行选择启用；如果同时启用两边的贴吧自动解析，同一条链接可能收到两份回复。需要单份回复时，可关闭其中一个插件的贴吧输出，或为独立版关闭自动解析并使用关键词触发。

不迁移或读取另一个插件的 Cookie 与配置。缓存目录留空时使用本插件自己的目录；自定义路径也建议分别设置。

## 解析范围

楼层回复来自接口返回的首屏，按楼层顺序选取，属于帖子回复预览。当前不提供全帖翻页、楼中楼或热度排行。删帖、权限限制、平台风控及失效的媒体签名会影响解析；可选 Cookie 不保证能够访问受限内容。

实现方法与核对来源见 [解析说明](docs/implementation.md)，版本记录见 [CHANGELOG](CHANGELOG.md)。
